# Развертывание собственного картографического сервиса (OSM)

Данный проект содержит инструкции и конфигурации для развертывания OSM-сервера в закрытом контуре на базе Debian 12.

## Структура проекта

- `docs/` — Пошаговые инструкции по установке, импорту и настройке Martin.
- `configs/` — Оптимизированные настройки PostgreSQL для разных конфигураций железа.
- `scripts/` — Скрипты для аудита и мониторинга системы.

## Быстрый старт

1. **Подготовка ОС**: Установите необходимые пакеты (см. `docs/01-setup.md`).
2. **Настройка БД**: Выберите подходящий конфиг из `configs/` и примените его.
3. **Импорт данных**: Используйте `osm2pgsql` для загрузки `.pbf` файлов (см. `docs/02-import.md`).
4. **Раздача тайлов**: Установите и запустите Martin (см. `docs/03-martin.md`).

## Мониторинг

Для проверки состояния сервера и базы данных используйте команды из файла:
`scripts/audit.txt`
