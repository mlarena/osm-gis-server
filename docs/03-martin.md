# Шаг 3: Установка и настройка Martin

**Martin** — это быстрый и легкий сервер векторных тайлов, написанный на Rust. Он позволяет транслировать данные из PostGIS (таблицы OSM) в формате MVT (Mapbox Vector Tiles) для отображения на картах (например, через MapLibre GL JS).

## 1. Установка

Для установки на Debian/Ubuntu скачайте последний релиз и установите пакет:


# Скачивание последнего релиза
wget https://github.com/maplibre/martin/releases/latest/download/debian-x86_64.deb

# Установка пакета
sudo dpkg -i ./debian-x86_64.deb

# Проверка установки
martin --help

# Удаление установочного файла
rm ./debian-x86_64.deb

# Проверьте установку
martin --version


## 2. Запуск

Для работы Martin требуется строка подключения к базе данных PostgreSQL.


# Пример запуска с подключением к базе gis
export PGPASSWORD='12345678'
martin postgresql://postgres@localhost:5432/gis

## 3. Особенности
- **Автоматическое обнаружение**: Martin сам находит таблицы с геометрией в PostGIS.
- **Производительность**: Высокая скорость генерации тайлов благодаря Rust.
- **Поддержка функций**: Позволяет создавать тайлы на основе SQL-функций.
